RFC 2324 is real. Section 2.3.2 is real. The status code (418) is real and was unofficially honored by browsers and frameworks for two decades before the IETF tried to deprecate it (people pushed back and won). The teapot is metaphorical. This page actually serves 200 OK because Azure Static Web Apps doesn't let me return a custom status code on a rewrite. The spirit is there.
